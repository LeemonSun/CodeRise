# Сборка CodeRise на Windows

GitHub Actions не используются. Тесты, сборка программы и установщика выполняются на своём компьютере.

## Требования

- Windows 10/11, 64-bit.
- 64-битный Python 3.11 или новее. Должна работать команда py или python.
- Доступ к интернету: нужны PySide6, Pillow, PyInstaller и встроенный Python с python.org.
- Inno Setup 6 (https://jrsoftware.org/isinfo.php) для получения установщика.

## Сборка за один запуск

В папке проекта запусти build_windows.cmd. Или выполни в PowerShell:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_windows.ps1
~~~

Скрипт создаёт виртуальное окружение, ставит библиотеки, проводит локальные тесты, рисует значок, собирает приложение, добавляет отдельный официальный Python runtime и запускает Inno Setup.

Пути после успешного завершения:

- dist/CodeRise/CodeRise.exe — исполняемый файл с папкой зависимостей.
- release/CodeRise-Setup-0.3.0.exe — установщик, если найден Inno Setup.

Внутри dist/CodeRise/runtime обязательно должен находиться python.exe. Без него собранное приложение запустится, но не сможет проверять ученический код. Встроенный Python скачивается непосредственно с python.org.

Если Inno Setup отсутствует, сборка приложения сохранится, а для установщика нужно установить Inno Setup 6 и повторить запуск.

Для сборки только приложения:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_windows.ps1 -NoInstaller
~~~

## Перед публикацией

Проверь установку и удаление на чистой Windows 10/11. Выполни упражнение с числовым вводом и русским текстом, открой справочник, исправь ошибку, закрой и снова открой приложение — прогресс должен сохраниться. Проверь разные масштабы Windows.

Установщик пока не подписан сертификатом издателя, поэтому Windows может вывести предупреждение SmartScreen. Отсутствие подписи не делает программу вредоносной, но перед распространением исходники и сборку надо проверять.

Приложение запускает ученический код локально и не является защищённой песочницей.
