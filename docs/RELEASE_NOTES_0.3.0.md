# CodeRise 0.3.0

Тренажёр Python для Windows. Учебный курс начинается с простых строк и заканчивается самостоятельными консольными задачами.

### Что внутри

- 140 заданий от G до SSS: ввод, условия, циклы, функции, работа с данными, ООП и алгоритмы.
- Четыре типа упражнений: допиши, исправь, предскажи, напиши сам.
- Два решения, понятные пошаговые объяснения и справочник из 137 понятий.
- Кнопка разбора строки, отдельная подсказка, теория главы и примеры тестов.
- Подсветка Python, номера строк, горячие клавиши.
- Автосохранение ответов, история попыток и возврат к сложным задачам.
- Проверка кода без зависания окна; лимиты времени и объёма вывода.

### Установка

После локальной сборки в Inno Setup установщик называется CodeRise-Setup-0.3.0.exe. Для работы установленной версии отдельный Python не нужен: он поставляется вместе с программой.

Тренажёр запускает написанный код на твоём компьютере и не является защищённой песочницей. Не вставляй непроверенные скрипты из интернета.

### Перед публикацией

Выполни build_windows.cmd на Windows. Скрипт запустит проверки, сделает снимки интерфейса, соберёт установщик и сохранит его в папке release. Убедись, что окно и русский текст выглядят правильно, а задания запускаются через встроенный Python.

Затем опубликуй через scripts/publish_release.ps1 при установленном GitHub CLI. Скрипт добавляет к релизу **только один файл — установочный EXE**.

Это описание релиза, а не подтверждение, что файл уже опубликован.
