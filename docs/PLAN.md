# План CodeRise

CodeRise должен учить писать код, а не нажимать «Дальше» после длинной теории.

## Как проходит одно задание

1. Короткое условие: что должно получиться.
2. Исходный код, если он нужен.
3. Человек пишет ответ или меняет программу.
4. Проверка запускает решение на нескольких входных данных.
5. При ошибке показывает, что ожидалось и что получилось.
6. Подсказка доступна по кнопке, разбор — после успеха.

Не сравнивать весь текст программы с «правильным» шаблоном: одну задачу можно решить разными способами.

## Дорога от G до SSS

| Ранг | Тема | Состояние |
| --- | --- | --- |
| G | print, переменные, числа, input | 6 заданий |
| F | if, elif, else, сравнения | 6 заданий |
| E | for, range, циклы | 6 заданий |
| D | строки, списки, простые функции | 6 заданий |
| C | словари, вложенные циклы, функции с аргументами | в плане |
| B | файлы, JSON, модули, обработка ошибок | в плане |
| A | классы, методы, разбиение программы на части | в плане |
| S | алгоритмы, тесты, отладка чужого кода | в плане |
| SS | самостоятельные небольшие программы | в плане |
| SSS | полный проект: от задания до выпуска | в плане |

Ранги показывают путь внутри тренажёра, а не квалификацию разработчика на рынке труда.

## Что добавить после первой версии

### Следующий выпуск
- Номера строк и более точные подсказки об ошибках Python.
- Сохранение черновика без смены задания.
- Больше тестов на краевые случаи.
- Возможность начать главу с короткой проверки знаний.

### Далее
- Пакеты заданий в отдельных JSON-файлах (проверять структуру перед загрузкой).
- Карта тем: видно, что уже изучено и где ошибки повторяются.
- Мини-проекты вместо одной строки: калькулятор, список дел, работа с файлами.
- Отдельный режим «без подсказок».

### Перед общим выпуском
- Проверки на Windows 10/11.
- Сборка .exe и понятный запуск без терминала.
- Тестирование всех заданий на нескольких правильных решениях.
- Чёткое предупреждение: вводимый Python выполняется локально, это не безопасная песочница.

## Принцип разработки

Сначала доводить уже работающий кусок, затем расширять курс. Лучше 24 проверенных задания, чем 200, которые принимают только одно решение или ломаются от правильного кода.
