# Дальнейшая работа

CodeRise 0.3: 140 заданий в десяти рангах, отдельные пошаговые пояснения, два решения, справочник и разбор ошибок. Прогресс сохраняется локально. Установщик собирается через Inno Setup на Windows.

Перед публичным выпуском осталось:

1. Пройти упражнения на реальном Windows 10/11, проверить ввод русских букв, все подсказки и запуск кода через встроенный Python.
2. Протестировать установку, обновление, удаление и сохранение прогресса.
3. Испытать интерфейс на масштабировании 100, 125, 150 и 200 процентов.
4. Изолировать запуск ученического кода более строго. Сейчас лимит по времени не предотвращает действия с файлами пользователя.
5. Добавить режим многофайловых проектов с проверкой структуры, а не только текста в консоли.
6. Попросить нескольких новичков пройти G–D без помощи автора. Исправить формулировки, где люди застревают.

Не гнаться за числом задач: непонятное объяснение и слабые тесты важнее дополнительного ранга.

Автоматических GitHub Actions нет. Программные проверки выполняются локально.
