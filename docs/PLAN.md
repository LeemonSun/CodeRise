## Что осталось улучшить перед полноценным выпуском

- Дизайн-контроль Windows: разные масштабы 100–200%, тёмная и светлая системная темы.
- Подсказки после типовых ошибок SyntaxError, NameError и IndexError, с привязкой к строке.
- Безопасный изолированный исполнитель Python. Пока пользовательский код запускается локально, без настоящей песочницы.
- Полноценные многофайловые проекты с проверкой структуры, а не только вывода в stdout.
- Сложные задания без предварительно подсказанного кода и независимый итоговый экзамен.
- Упаковка локально в .exe и финальное ручное тестирование GUI на Windows.

## Как писать новые задания

1. Условие без лишней теории.
2. Не менее двух тестовых случаев, включая неудобный или граничный.
3. Два корректных решения с разным подходом.
4. Объяснение простыми словами, без «магии».
5. Короткая подсказка, которая помогает думать, а не сразу выдаёт ответ.
6. Проверка обоих решений локально.

Исходники курса в `coderise/data/course_data.json` и `coderise/data/legacy_data.json`. Ранги внутри приложения не являются профессиональной сертификацией.

**GitHub Actions только по ручному запуску**, чтобы не расходовать лимиты при каждом сохранении кода.
