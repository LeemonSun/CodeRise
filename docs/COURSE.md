# Курс CodeRise

140 заданий: по 14 на ранг. Короткая практика чередуется с исправлением ошибок и разбором чужого кода.

| Ранг | Что изучаем | Заданий |
| --- | --- | ---: |
| G | print, input, переменные, числа | 14 |
| F | условия, сравнения, пороговые значения | 14 |
| E | циклы, range, накопление сумм | 14 |
| D | строки, списки, индексы | 14 |
| C | функции, словари, множества | 14 |
| B | JSON, CSV, ошибки ввода | 14 |
| A | классы, поля, методы, наследование | 14 |
| S | поиск, сортировка, рекурсия, графы | 14 |
| SS | небольшие программы с командами | 14 |
| SSS | интегрированные задачи: очереди, расписания, данные | 14 |

Ранг SSS обозначает завершение курса. Это не профессиональная аттестация.

## Как пользоваться

1. Сначала прочитай условие и попробуй определить вход и ожидаемый результат.
2. Пиши свой вариант. Можно использовать другие имена переменных и алгоритмы, если вывод правильный.
3. Нужна небольшая подсказка — нажми «Подсказка». Не знаешь оператор — «Разобрать строку». Для целой темы есть «Теория главы».
4. Ctrl+Enter проверяет решение. Если Python упал, прочитай понятное объяснение и исходный текст ошибки.
5. После успешной попытки открой «Два решения» и сравни их. Там же — реальные примеры ввода и вывода.
6. Задания, где раньше были ошибки, доступны через «Вернуться к сложным заданиям».

Например, в range(1, 6) попадают числа 1, 2, 3, 4, 5, но не 6. Если непонятно, почему цикл работает именно так, распиши по шагам значение переменной i.

## Проверка

Тренажёр сравнивает результат кода с ожидаемым выводом на нескольких наборах входных данных. Это не полноценный анализ качества программы: правильный ответ ещё не означает хорошую архитектуру или скорость.

Для составления своих заданий используется открытый JSON-файл coderise/data/course_data.json. Поля: id, stage, kind, prompt, starter, tests, hint, explanation, walkthrough, methods, concepts.

Форматы kind: predict, fill, fix, write. Для задач с исполнением нужны тесты с граничными случаями, для предсказания вывода — точный answer. Каждый пример решения должен проходить проверки.
