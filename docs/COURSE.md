# Как учиться в CodeRise

Курс начинается с самых простых действий в Python и заканчивается маленькими консольными проектами. Ранги — названия глав, а не реальные должности или квалификация программиста.

## На каждом задании

1. Прочитай условие и попробуй объяснить его своими словами.
2. Посмотри на начальный код. Если незнакомое слово — открой «Что за что отвечает».
3. Напиши решение. Начни с длинного и понятного варианта; сокращения успеются позже.
4. Нажми «Проверить». Код проверяется на разных входных данных.
5. Если ошибка — сравни ожидаемый и полученный результат. Используй подсказку, затем попробуй снова.
6. После успеха открой «Два способа решить» и сравни варианты. Перепиши решение своими словами.

## Ограничения

- Проверяется результат работы программы, а не стиль кода и не обязательное использование названного алгоритма. Можно получить верный вывод неудачным способом: сравни своё решение с разборами.
- Встроенная проверка исполняет написанный пользователем Python-код на его компьютере с ограничением времени. Это **не песочница**. Не запускай код из случайных источников.
- Данные для упражнений хранятся в `coderise/data/course_data.json` (редактируемый JSON). Справочник — там же, поля `topics` и `guides`.
- `.exe` собирается по желанию вручную; изменения не запускают GitHub Actions автоматически.

## Для разработчиков

Все задания собираются в `coderise/curriculum.py`. Новый ранг добавляется в `coderise/data/course_data.json` (список `stages`), а сами задачи — в `exercises`. Основные поля: `id`, `stage`, `title`, `kind`, `prompt`, `starter`, `tests`, `hint`, `explanation`, `walkthrough`, `methods`, `concepts`.

Проверка курса локально:

```shell
python -m unittest discover -s tests -v
```

Интерфейс на PySide6, зависимости находятся в `requirements.txt`. Для запуска:

```shell
python -m pip install -r requirements.txt
python main.py
```
