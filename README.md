# CodeRise

**Тренажёр Python — от первой строки до своих проектов.**

CodeRise рассчитан на человека, который ещё путается в `if`, `for` и `input`. Задания становятся сложнее постепенно: сначала выбрать результат, потом дописать одну строку, исправить ошибку и наконец написать программу самому.

Короткая теория доступна прямо во время решения. Если забыл, что означает `self` или зачем нужен `return`, не нужно выходить из задания.

## Что внутри

- **120 упражнений и 10 рангов от G до SSS** — от вывода текста до алгоритмов, файлов, классов и небольших проектов.
- **Четыре формата заданий**: предскажи вывод, допиши код, исправь ошибку, реши самостоятельно.
- **Несколько проверок на каждое практическое упражнение**. Можно написать свой правильный вариант.
- **Два примера решения для каждого упражнения** и пошаговый разбор.
- **137 статей справочника Python**, примеры использования и частые ошибки.
- **Кнопки «Что за что отвечает?», «Теория главы» и «Два решения»** прямо под редактором.
- **Поиск по упражнениям**, прогресс по рангам, очки XP, сохранение черновиков и решённых задач.
- Тёмный интерфейс на PySide6; подсветка Python, пробелы вместо Tab и автоматические отступы.

Ранги — только игровая система прогресса внутри приложения, а не оценка профессионального уровня.

## Как запустить

Нужен Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
python main.py
```

Для проверки исходников **на своём компьютере**, без GitHub Actions:

```powershell
python -m unittest discover -s tests -v
```

Чтобы собрать Windows `.exe` **локально**:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name CodeRise --add-data "coderise/data/*.json;coderise/data" main.py
```

Готовый файл будет в `dist/CodeRise.exe`. Сборка неподписанная.

**GitHub Actions не запускаются автоматически.** Тесты и сборку в Actions можно запускать только вручную; при обычной загрузке изменений лимиты Actions не расходуются.

## Где что лежит

| Путь | Для чего |
| --- | --- |
| `main.py` | запуск программы |
| `coderise/app.py` | основное окно |
| `coderise/editor.py` | редактор с подсветкой |
| `coderise/study_views.py` | теория, два решения и справочник |
| `coderise/content.py` | первые 24 упражнения |
| `coderise/data/course_data.json` | ещё 96 упражнений и справочные материалы |
| `coderise/data/legacy_data.json` | разборы и решения первых 24 заданий |
| `coderise/curriculum.py` | полный курс и порядок рангов |
| `coderise/engine.py` | запуск пользовательского кода и проверка результата |
| `coderise/progress.py` | локальное сохранение прогресса |
| `docs/COURSE.md` | структура учебных глав |
| `tests/` | проверка заданий и логики |

На Windows прогресс сохраняется в `%APPDATA%\CodeRise\progress.json`. На других системах — `~/.coderise/progress.json`.

## Важный момент

CodeRise выполняет введённый Python-код **на твоём компьютере**. Время выполнения ограничено, но настоящей изолированной песочницы нет. Не вставляй чужой код, которому не доверяешь.

## Цель проекта

Не заставить человека выучить 120 готовых ответов, а научить читать код, разбираться в ошибках и постепенно решать задачи без подсказок. Прохождение всех рангов не заменяет полноценной практики и самостоятельных проектов.
