# CodeRise

Тренажёр Python: от первого print до собственных консольных программ.

Здесь можно не только писать код, но и разбирать его по строчкам. Непонятный оператор — ставь курсор на строку и нажимай «Разобрать строку». Застрял на задаче — есть короткая подсказка, объяснение и два примера решения.

## Что готово

- 140 заданий, по 14 на каждый ранг от G до SSS.
- Четыре формата: предсказать вывод, дописать строку, исправить ошибку, написать программу.
- Пошаговые пояснения к каждой задаче и два способа решения.
- 137 понятий в справочнике с примерами и типичными ошибками.
- Проверка решений на нескольких тестовых наборах.
- Понятные пояснения SyntaxError, NameError и других ошибок Python.
- Поиск по заданиям, подсчёт попыток, возврат к сложным задачам.
- Автосохранение черновиков и прогресса.
- Тёмный интерфейс с подсветкой Python.

G–SSS — игровые обозначения глав, не оценка квалификации разработчика.

## Запуск исходников

Нужен Python 3.11 или новее:

~~~powershell
python -m pip install -r requirements.txt
python main.py
~~~

Проверить всё локально:

~~~powershell
python -m unittest discover -s tests -v
~~~

## Установщик Windows

Сборка проходит на твоём Windows-компьютере, без GitHub Actions. Нужны 64-битный Python 3.11+, интернет для установки зависимостей и Inno Setup 6.

Дважды нажми build_windows.cmd в корне проекта. Скрипт проверит код, соберёт приложение, добавит отдельный Python для решения задач и создаст установщик.

После успешной сборки:
- release/CodeRise-Setup-0.3.0.exe — готовый установщик (если установлен Inno Setup 6);
- dist/CodeRise/CodeRise.exe — программа без установки.

Ученик сможет работать с собранным приложением без установленного Python. Установщик добавляет ярлык в меню «Пуск»; значок на рабочем столе — по выбору. Установка не требует прав администратора.

Подробности — в docs/BUILD.md.

В репозитории находятся исходники установщика. Подписанный готовый релиз пока не опубликован: перед распространением нужно собрать его и проверить на Windows.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| coderise/app.py | окно, навигация, прогресс |
| coderise/editor.py | редактор Python |
| coderise/study_views.py | уроки и решения |
| coderise/line_help.py | разбор текущей строки |
| coderise/error_guide.py | объяснения ошибок |
| coderise/data/course_data.json | упражнения и справочник |
| coderise/curriculum.py | порядок глав |
| coderise/engine.py | проверка выполненного кода |
| coderise/progress.py | черновики, попытки, решённые задачи |
| scripts/build_windows.ps1 | локальная сборка |
| installer/CodeRise.iss | установщик Windows |
| tests/ | локальные тесты |

На Windows прогресс хранится в %APPDATA%\CodeRise\progress.json. Удаление программы не стирает историю обучения автоматически.

## Безопасность

Код, написанный в тренажёре, выполняется на компьютере пользователя. Ограничение времени есть, полной песочницы нет. Не запускай неизвестные скрипты из интернета.

GitHub используется только для хранения исходников: автоматические Actions удалены.

Программа курса: docs/COURSE.md.
