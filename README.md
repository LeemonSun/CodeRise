# CodeRise

Небольшой тренажёр Python для тех, кто начинает с нуля.

Здесь не нужно сразу писать целую программу. Сначала разбираешь готовые примеры, потом дописываешь строки, исправляешь ошибки и постепенно переходишь к собственным решениям.

## Что уже есть

- 24 задания в четырёх разделах: основы, условия, циклы, списки и функции.
- Четыре формата: угадай вывод, допиши код, найди ошибку, реши сам.
- Проверка ответа по нескольким тестам, а не по совпадению с одним шаблоном.
- Подсказки, результат проверки и сохранение прогресса.
- Тёмный интерфейс для Windows, написанный на PySide6.

## Запуск

Нужен Python 3.11 или новее.

1. Скачай репозиторий.
2. Открой терминал в папке проекта.
3. Установи зависимости:

   python -m pip install -r requirements.txt

4. Запусти приложение:

   python main.py

Для проверки логики без запуска интерфейса:

   python -m unittest discover -s tests -v

## Как устроен проект

- coderise/content.py — сами задания. Новые упражнения добавляются сюда.
- coderise/engine.py — запуск и проверка решений.
- coderise/progress.py — локальное сохранение.
- coderise/app.py — интерфейс.
- tests/ — проверки основных механизмов.

Прогресс хранится только на твоём компьютере: в %APPDATA%\CodeRise\progress.json на Windows или ~/.coderise/progress.json на других системах.

## Важно

CodeRise запускает введённый Python-код на твоём компьютере. Есть ограничение времени выполнения, но полноценной песочницы нет. Не запускай через тренажёр чужой или непроверенный код.
